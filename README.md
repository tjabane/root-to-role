# Root to Role

**Learn. Build. Apply.**

Root to Role is a planned web application that turns real tech-job requirements
into a skill tree. A user connects selected GitHub repositories, sees evidence
of what they have built, chooses what to learn next, and finds relevant jobs
with application links.

The project also supports weekly experiments: set a starting profile, learn
and build, track applications and interview outcomes, and use the experience
to improve the product.

## Status

Planning. The [draft specification](docs/spec.md) describes the first release,
data quality rules, and later features.

## Data source

The initial job data comes from the Gold technology-jobs layer in
[melo-kgodumodumo](https://github.com/tjabane/melo-kgodumodumo). This web
application is a separate project from both that data pipeline and the proposed
job-context MCP server.
